# GoonBet Share Guide

## Local

Run:

```bash
node server.mjs
```

Open:

`http://localhost:4173`

## Public

Best simple path:

- Push to GitHub
- Deploy as a Node Web Service on Render
- Add the same environment variables from `.env.example`
- Use build command `npm install`
- Use start command `node server.mjs`
- Share the public URL with friends

## Live sources

- Fixtures: `football-data.org`
- Coefficients: `The Odds API`

## Current login

- Simple name + email account
- Shared through the app server
- Good for a small private pool
